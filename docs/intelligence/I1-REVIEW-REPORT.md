## 7. Model architecture decisions

Candidate A is a structured-feature multitask MLP. Candidate B adds bounded temporal and graph encoders before a compact model. Candidate C is an optional pretrained text backbone, potentially Qwen3-0.6B-based; it is not the default and was not downloaded. Resource comparisons label estimates as estimates.

## 21. Final-review clarification — experiment scope and validity

The detailed clarification is in [05-i1-experiment-results.md](05-i1-experiment-results.md). The experiment's model input is exactly `[current_occupancy_bit, door_open_bit, motion_bit]`; the 3-6-1 tanh/sigmoid MLP has 31 trainable parameters. The generator computes `next = current XOR (door_open AND motion)` and independently flips the generated target with 2% probability. It applies that same rule to all homes. The home holdout changes each home's sampled sensor rates, initial state, and realized sequence, but does not hold out a transition mechanism or topology.

The review found no direct target-column, future-record, home-ID, or step-index input. It did find strong intentional feature-to-label coupling: the label is almost fully determined by the three input bits under a single shared synthetic rule. Thus 98.24% is the observed result on 1,536 fixed synthetic held-out records (1,509 correct), not a real-home or general reasoning estimate. The 82.36% last-state baseline ignores the door/motion conjunction and is correct when generated occupancy stays unchanged; it misses many rule-triggered toggles and noisy flips.

Per-class test supports and metrics have been derived from the saved confusion counts and documented in the experiment-results report. Temporal reasoning and topological reasoning remain NOT DEMONSTRATED: the model receives no history window or temporal signals and no graph/topology representation. Alternative-rule generalization, a separate leakage stress test, and real-world task quality are NOT MEASURED. The proposed I2/I3 hypotheses in the results report are research questions only and do not authorize those milestones.

The experiment was rerun once to a temporary output and compared byte-for-byte with the preserved `research/i1/results.json`; comparison passed. The result artifact was not rewritten. The clarification changed documentation only and did not change the experiment, model, or implementation. Following that clarification, the owner explicitly approved I1. **I1 is approved as an experimental milestone; this does not qualify the experiment as production-ready or authorize I2/I3.**
